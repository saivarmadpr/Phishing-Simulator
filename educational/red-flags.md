# Red Flags of Phishing Emails

## Common Red Flags
1. **Mismatched URLs**: Hover over links to check the actual destination.
2. **Generic Greetings**: Phrases like "Dear Customer" instead of your name.
3. **Urgent or Threatening Language**: Messages pressuring immediate action.
4. **Suspicious Attachments**: Unexpected file formats or unsolicited documents.

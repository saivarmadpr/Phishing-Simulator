# Competition Rules 📝

## Objective
Create a realistic phishing email to simulate phishing attacks and educate recipients on identifying red flags.

## Restrictions
1. No actual malicious links, attachments, or code.
2. No use of real personal or sensitive information.
3. Must be purely for educational purposes.

## Submission Format
1. Send the email to your own address.
2. Download the email and attach it to the submission form.
3. Provide a brief description (200–300 words) explaining the approach and tactics.

## Prohibited Actions
- Using malicious software or attempting real phishing attacks.
- Violating ethical boundaries or using unauthorized data.
